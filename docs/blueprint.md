# **App Name**: CLR Portfolio

## Core Features:

- Dynamic Content Rendering: Dynamically render information (resume, work experience, skills, projects, and awards) directly from the provided JSON data.
- Interactive Skill Showcase: Visually represent skills with interactive elements. e.g., clickable skills leading to project examples.
- Project Highlighting: Dedicated sections to display projects with descriptions, links, and keywords for easy filtering.
- Contact Form with Email Integration: Implement a contact form that allows visitors to send you emails directly from the website.

## Style Guidelines:

- Primary color: Deep navy blue (#1A237E) to convey professionalism and trustworthiness.
- Background color: Light gray (#F5F5F5) to ensure content legibility and reduce eye strain.
- Accent color: Soft amber (#FFB300) for highlights and call-to-action buttons, providing a warm and inviting touch.
- Body font: 'Inter', sans-serif, for a modern and neutral look, suitable for continuous reading.
- Headline font: 'Space Grotesk', sans-serif, to reflect technical skill and make the headers stand out.
- Use a consistent set of professional icons to represent skills, technologies, and contact information. Ensure icons are simple and easily recognizable.
- Implement a clean and responsive layout that adapts to different screen sizes. Use clear section dividers and white space to improve readability.
- Incorporate subtle animations on hover states and page transitions to add a touch of interactivity and engagement without being distracting.
